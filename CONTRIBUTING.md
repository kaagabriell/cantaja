# Contributing to CantaJá

Thank you for considering a contribution.

## Ways to contribute

- Report reproducible bugs.
- Propose focused enhancements.
- Improve documentation.
- Submit fixes or features through pull requests.

## Development workflow

1. Create an issue or describe the problem the change solves.
2. Create a focused branch.
3. Keep changes scoped and avoid unrelated refactors.
4. Run `npm run lint` and `npm run build` before opening a pull request.
5. Explain what changed, why it changed, and how it was validated.

## Security

Do not disclose vulnerabilities, credentials, tokens, personal data, or other sensitive material in public issues. Follow `SECURITY.md` for security reports.

## Licensing

Contribution licensing terms will be finalized before the repository is made public. Do not assume a license grant beyond applicable law until a LICENSE file is published.
